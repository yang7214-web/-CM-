모바일 & 타 PC 공유 및 배포 방법

404 오류 없이 누구나 100% 실행할 수 있는 방법입니다.

모바일 404 Not Found 오류가 발생했던 원인

현재 작업 화면은 사용자의 임시 세션 컨테이너에서 동작하므로, 브라우저 주소창 주소를 그대로 모바일이나 타인에게 보내면 접근 권한이 없어 Google 404가 뜹니다.

1 가장 쉬운 방법: HTML 단일 파일 공유 (추천 ⭐⭐⭐)

아래 버튼을 눌러 `cm_dashboard.html` 파일을 다운로드한 뒤, 카카오톡/팀즈/이메일로 전달하세요. 수신자가 파일을 클릭하기만 하면 모바일(삼성인터넷, 사파리, 크롬)이나 PC 어디서든 즉시 실행됩니다!

2 시뮬레이션 데이터 코드 (클립보드 복사 & 불러오기)

현재 입력된 차종 MIX, SAP 실적 수치를 텍스트 코드로 복사하여 다른 기기에서 불러올 수 있습니다.

3 영구 URL 링크로 운영하고 싶을 때 (사내 웹 서버/그룹웨어)

이 파일은 단 1개의 파일로 모든 기능이 작동하는 완전 독립형 Single-file Web App입니다. 회사 인트라넷 서버, 사내 그룹웨어 게시판, 또는 무료 웹 호스팅(GitHub Pages, Vercel, Netlify)에 파일 1개만 업로드하시면 전사 임직원이 접속 가능한 고유 웹 주소가 생성됩니다.

엑셀 데이터 일괄 붙여넣기

엑셀 표에서 여러 행을 복사(Ctrl+C)하여 한 번에 일괄 적용합니다.

💡 붙여넣기 방법:
엑셀에서 [모델코드, 판매대수, 장착대수, 커스텀매출] 열 또는 [판매대수, 장착대수, 커스텀매출] 3개 열을 복사하여 아래 입력창에 붙여넣기(Ctrl+V)하세요. 쉼표(,)나 탭 구분 모두 지원됩니다.
